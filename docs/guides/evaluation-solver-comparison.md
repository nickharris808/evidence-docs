# Reviewing capacitance output comparisons

This is a bounded review and test proposal, not a report of a new executed experiment.

## Technical excerpt

Before comparing capacitance outputs, review conductor ordering, reference potential, matrix reduction, signs, and units. Keep raw output beside the normalized matrix. Then report candidate-to-reference error against each solver and reference-to-reference discrepancy on the same geometry ID. An unexplained excluded reference solve is not a candidate win. Proposed review protocol, not a new result. Public comparison scope: https://verifycorelabs.com/theorems/independent-solver-anchors/
